# PasosHoy

Estado de los pasos fronterizos entre Argentina y Chile, con el organismo que informa cada dato y la hora de su última actualización.

- Sitio: https://pasoshoy.com
- Cómo trabajamos los datos: https://pasoshoy.com/metodologia/
- Repositorio público: [pasos-fronterizos-argentina-chile](https://github.com/pasoshoy/pasos-fronterizos-argentina-chile), la lista de los pasos para cruzar en vehículo y las fuentes oficiales de su estado.

Ante la duda, PasosHoy no dice "Abierto": dice "Sin confirmar" y muestra el último dato oficial al lado.
